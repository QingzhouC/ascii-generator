# Image Generation
- 导入内容识别为图片时自动使用新的图片转换参数，强调明暗对比和层次感；视频生成保持现有参数。
- 视觉特效偏好流动感的水波纹样式而非静态生硬效果，从视频动态切换到定格画面的过渡需丝滑流畅，定格后仍保留波光粼粼的质感，小部分符号持续闪烁

# UI/UX
- 水波纹扩散效果仅在鼠标点击时触发，空白区域点击产生带字符的涟漪，鼠标移动时不产生任何波纹；画面定格后若鼠标无移动或点击操作，也不出现涟漪
- 用户认为蓝色字体可读性差，偏好清晰、高对比度的文字颜色，界面文字应避免使用难以辨认的蓝色。
